THE OTTER COMET — a tiny procedural artist. The program draws its own entry image at runtime: a helmeted otter astronaut riding a blazing comet through a shattering crystal ring into a golden star-portal, rendered with a hand-written SDF rasterizer and PNG encoder. Node standard library only, fully deterministic — every run writes the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
